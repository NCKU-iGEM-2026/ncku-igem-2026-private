Interim · work in progress

This page records a temporary capability, not our finished software. The telemetry link described below was built to prove that a reading can travel from a sensor to a browser, and it will be superseded once the tool it was preparing for is ready.

Our main effort is a dose–response analysis service for plate-reader exports. It is under active revision and is deliberately not described here yet: we would rather document it once its behaviour is settled than publish an account we would have to correct.

The GY-302 telemetry link

The GY-302 is a breakout board for the BH1750FVI, an ambient-light sensor that reports illuminance directly in lux over I²C. It measures nothing biological, and that is why it was chosen: because its output needs no interpretation, it lets the transport be tested on its own terms, with any failure attributable to the path rather than to the measurement.

GY-302 sensor → ESP32 → FastAPI service → Browser readout

The device samples every 500 ms and uploads the most recent value every 3 s; the browser polls for it every 2 s and plots a rolling window of the last 30 readings. An indicator LED is driven below 50 lux from the device's own reading rather than from a server response, so it keeps working when the network does not.

Screenshot of the live readout — to be added

Its limits follow from its purpose. The service holds a single reading in memory, so there is no history, no support for more than one device, and no authentication on the upload. The sensor has not been calibrated against a reference photometer, so its readings are not quantitative. None of this is a defect to be fixed in place — it is the scope we chose for a stepping stone.
